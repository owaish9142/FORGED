
# FORGED 💪
### Earn Your Strength.

FORGED is an Android fitness challenge application designed to make daily exercise more engaging through randomized workout challenges, progression, and task tracking.

## 🚀 Features

- **Random Workout Challenges:** Get assigned different exercises.
- **XP & Ranking System:** Earn experience points and progress through ranks.
- **Daily Challenges:** Manage daily workout limits and goals.
- **Task Tracking:** Track completed and pending workouts.
- **Customizable Active Hours:** Configure when challenges can be issued.
- **Notifications:** Receive workout reminders and interact with assigned tasks.
- **Local Data Storage:** Save workout progress and application settings.

## 🛠️ Technologies Used

- Kotlin
- Jetpack Compose
- Android SDK
- Android DataStore
- BroadcastReceiver
- Android Notifications
- Gradle
